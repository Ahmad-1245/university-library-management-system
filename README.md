# University Library Management System

## About
Our university library uses manual records or an old system to manage books, members and overdue items. This project plans a new Library Management System (LMS) that makes this easier. We are analysing the problem, writing requirements, drawing UML diagrams and designing a prototype. We are not building the full system.

## Objectives
- Find out what the library, students and staff need.
- Write clear requirements (SRS).
- Draw UML diagrams of the system.
- Design a clickable prototype in Figma.
- Use Git and GitHub to manage our work.

## Scope
**In scope:** books, members, borrowing, returning, reservations, overdue notifications.

**Out of scope:** building the full software, payments, connecting to other university systems.

## Assumptions
- Every member has a unique ID.
- The library has a fixed loan period.
- Users have internet access and a web browser.

## Constraints
- We must finish before the deadline.
- Only three team members, working part-time.
- We only use free tools (GitHub, Figma, diagrams.net).
